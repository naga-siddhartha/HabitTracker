# Habit: Grab It - Modernization Plan

Guiding rule: lightweight and bloat-free. Prefer system components over custom chrome, add no new dependencies, and only add features that remove friction from the daily check-in.

1. **Correctness** (done): streaks (weekly schedules, live-streak off-by-one, interval habits, longest recompute), deterministic same-day entry lookup with CloudKit duplicates, time zone travel, reminder remove/add race, 64 pending notification cap, Siri intent consistency, backup restore recomputes streaks, unit tests.
2. **Sync and data safety** (done): no container-swap "Sync now" (status row instead, from real CloudKit events), no silent in-memory fallback, duplicate habits/entries merged on launch and after every iCloud import (deterministic across devices), duplicate names blocked when adding, sign-out actually stops sync, account deletion deletes the iCloud copy, backups keep reminders, emoji, custom color and interval progress.
3. **Remove Ads purchase + usage metrics**:
   - Metrics (code done, needs setup, see `docs/METRICS.md`): App Store Connect + Xcode Organizer for active devices, retention, crashes, hangs and launch time; TelemetryDeck for product KPIs via one anonymous daily summary plus a few lifecycle events. Opt-out in Settings. Privacy policy update is on the `privacy-usage-stats` branch of the website repo; publish it with the build.
   - Remove Ads (code done): one-time non-consumable `com.nagasiddharthadonepudi.HabitTracker.removeads` via StoreKit 2, no extra SDK. Buyers never load AdMob; "Remove ads" link on the ad card; Remove Ads + Restore Purchases in Settings; refunds revoke it; Family Sharing on. Local testing uses `HabitTracker.storekit` (wired into the HabitTracker scheme). Needs the product created in App Store Connect. **Price: $2.99** (US base; Apple converts other storefronts). Comparable habit apps charge $4.99-$8.99 one-time, but those unlock features; removing ads alone sits a tier lower. Revisit after 4-8 weeks: under ~1% of MAU buying, try $1.99; a future "Pro" bundle with real features would go to $4.99. Later option: drop AdMob entirely and rely on the purchase plus an optional tip jar.
4. **Performance and code health** (done): widget/tests target iOS 17.6 / macOS 14; streaks computed when shown; launch housekeeping after first frame; per-day entry index; `@Observable`; Swift 6 language mode; `HabitStore` testable with an in-memory database; comment conventions in `docs/CODE_STYLE.md`.
5. **UI refresh (iOS 26/27 Liquid Glass)** (in progress on `modernization/phase-5-ui`):
   - Done: Home logic in tested `TodaySnapshot`; system styling (no custom shadows/backgrounds/tab bar overrides); violet + gold brand system; glass + button; completion haptics; swipe to complete/skip (27+); onboarding sheet and clean empty state; inline color swatches and compact emoji sheet; progress ring with next-habit emoji and drawn gold check; perfect-day streak; next-habit copy; streak milestone banners; `AddEditHabitView` split.
   - Remaining: widgets (tap to complete, lock screen, Control Center, violet/gold), accessibility pass (Dynamic Type, VoiceOver), resizable iPhone layout check.

Later: X-times-per-week goals, vacation mode on top of skip, optional note per check-in.
